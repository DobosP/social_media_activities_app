# Native media boundary

`Processor` accepts a quarantined local file and returns a typed processing
manifest. Source bytes are streamed through SHA256; image headers are checked
before decoding. Defaults bound images to 5 MiB, 30 MP and 2048 pixels per side,
with an eager 800-pixel rendition. Native libavif/libaom encodes AVIF at quantizer
23 (the quality-64 mapping), lossless alpha and two threads; FFmpeg/libwebp encodes
WebP at quality 80. EXIF orientation is baked into pixels and metadata is removed.

The Go difference fingerprint uses luminance and antialiased Lanczos-3 resizing.
Its 18 synthetic golden cases were generated by the existing Pillow reference,
including transparency and narrow images. It remains a duplicate heuristic.
Original digests and frame fingerprints still require an effective scanner.
Managed scanner responses must contain an explicit boolean `match` or `flagged`;
missing, duplicate, null and false-like values fail closed. PDFs pass bounded
ClamAV INSTREAM scanning and always require download disposition when served.

Video admission creates a withheld row and stores a private quarantined source.
An off-request worker uses short claim/finalization transactions around codec
work: MP4/WebM and codec whitelists, file-only protocols, a 90-second/3840-pixel
source ceiling, 1280-pixel progressive H.264/AAC output, AVIF/WebP poster and
bounded frame-zero-inclusive screening. `prlimit` bounds child address space and
CPU; cancellation kills its entire process group. A transient failure waits for
the stale claim window; three attempts exhaust the job. Terminal failures erase
source bytes; safety-blocked sources remain private evidence and never have an
in-app byte URL, including for staff.

`Service` implements the existing media APIs and shared attachment/place-cover
operations. Authorization comes from the owning social domain, is reloaded after
codec work, and is checked again at serving. Signed references bind model/ID,
viewer, variant and expiry with a purpose-specific MAC. Anonymous cover tokens
only cover freshly public adult activities or public venues. Child attachments
have a 24-hour TTL floor; adults have a one-hour floor. Hides, unresolved reports
and unlifted removal actions preserve temporary-media evidence.

`EnsureSchema` adds private manifests, an avatar-attempt brake and a durable blob
deletion outbox. Delete triggers capture all main/thumbnail/poster/source keys
for direct SQL and account/domain deletion paths. `DrainBlobDeletions` retries
physical erasure after SQL commits. Caller-owned account erasure authorization
and deletion of the complete relational graph remain mandatory.

`LocalStore` is the development backend. `S3Store` requires explicit verified EU
residency and a private bucket, HTTPS, immutable object references, bounded range
reads and private presigns of at most 60 seconds. It creates no bucket or provider.
R2/MinIO endpoints are rejected. Bucket ACL/residency verification, credentials,
scanner configuration, codec container isolation and production activation remain
operator responsibilities. No test reads live uploads or environment credentials.

Native runtime packages are `ffmpeg`, `libavif-bin`, and `util-linux` (`prlimit`).
`CheckRuntime()` belongs to startup when upload processing is enabled. Global
session/CSRF middleware must wrap mutation routes; media authorization does not
replace session validation. The serving container also needs capability drops,
no privilege escalation and CPU/memory/PID limits.

Pure tests run with `go test -race ./internal/media`. Actual codec tests execute
when native tools are installed. PostgreSQL tests require an explicit disposable
`-media-test-dsn`; each clones and drops only its own `media_native_test_*` schema.
The full gate is `go test -race ./internal/media -media-test-dsn=<fixture DSN>` in
the qualified codec runtime. Missing native tools or a missing explicit DSN are
reported as skipped integration checks, never as a qualified production result.
