# Native public legacy pages

The host routes preserved templates through `PublicView`, `PublicAction` and
`PublicDownload`. Public places/events always share the canonical catalog publication
predicate; pending venue/event details retain only the source proposer/staff carve-out
and never emit structured data or a name-bearing canonical URL. Source list/map filters,
accessibility/fact/vote summaries, corrections, accuracy reports, hours/closure overlays,
private steward claims and rights-confirmed official cover uploads use native services.
Partner revocation or reassignment removes the official-image affordance.

City/activity landings advertise only live public supply. Public discovery is hard-coded
to adult, explicitly listed activities/groups. Feeds, sitemaps, robots/LLM guidance,
whitelisted rooted snapshot downloads and public schema/docs responses are cookie-free.
Rendered account-bearing pages remain private. No social Activity JSON-LD builder exists.
Safe Event/Place/Dataset JSON-LD preserves source commerce, lifecycle, attribution and
location facts, and escapes script-breaking characters before safe embedding.

The OpenAPI document includes the generated native API operation inventory and explicit
public event/place/taxonomy/discovery field schemas. Private route entries identify their
authentication/CSRF gates honestly and leave their field-level DTO schema unspecified;
full private serializer documentation remains necessary for complete Django schema parity.
Qualification uses `-web-domain-test-dsn` with synthetic real-FK schemas, plus pure
crawler/XML/JSON escaping and rooted snapshot tests.
